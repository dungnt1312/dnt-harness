# bench-discount-bug

A tiny shopping-cart pricing library.

- `src/catalog.js` — product catalog and unit prices (in cents)
- `src/money.js` — cent conversion helpers
- `src/discounts.js` — applies an ordered list of percent/fixed discounts
- `src/cart.js` — cart line items, subtotal and total

Run the suite:

```
npm test
```
